# Changelog

## 0.3.3 - 2026-11-14

- Give the expanded Fusion 26 catalogue a separate index so earlier controllers can still check for and install their own updates.

## 0.3.2 - 2026-11-14

- Add eight plugins to Fusion 26, including official Gravity Forms add-on identities.
- Mirror the three new WordPress.org plugins: Font Awesome, Query Monitor and Search Regex.

## 0.3.1 - 2026-11-14

- Remove the redundant Manual checks only label from the controller status line.

## 0.3.0 - 2026-11-14

- Include Fusion Plugins in the Fusion 26 catalogue and its own update flow.
- Index the verified controller release ZIP alongside mirrored plugins, while retaining the older public-only feed.

## 0.2.2 - 2026-11-14

- Show Fusion mirror checks, package progress, errors and batch results in a modal matching the other controllers.
- Refresh the plugin list after a check or batch without relying on an inline status notice.

## 0.2.1 - 2026-11-14

- Remove the redundant Mirror column from Updates available. The available version still links to its mirrored release.

## 0.2.0 - 2026-11-14

- Add manual mirror checks and selected plugin updates from verified GitHub ZIPs.
- Group catalog cards and show descriptions, versions, requirements and actions.
- Move catalog selection into Catalogue; remove Settings and the separate Catalogs tab.
- Use the latest mirrored version without a separate approval step.

## 0.1.1 - 2026-11-14

- Show actionable updates only in the Updates available tab.

## 0.1.0 - 2026-11-14

- Add Fusion 26 with 16 curated plugins and catalog selection.
- Add optional approved mirror installs without changing native WordPress updates.
- Add daily and manual WordPress.org mirroring, weekly supported-catalog checks, and separate approval metadata.
